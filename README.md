# VibeLocal
VibeLocal Android Application

VibeLocal is an Android application designed to help users discover and explore local events and activities based on their interests and location.

## Features

- User registration and login
- Browse local events
- Search for events
- Filter events by category and interests
- View detailed event information
- Save events for later
- Interactive map for discovering events
- Notifications
- User profile
- Interest-based event discovery
- Local event data storage

## Technologies Used

- Kotlin
- Android Studio
- XML
- Room Database
- Firebase
- REST API
- Google Maps / Maps integration
- Gradle
